# Task 2.2 — Worker: Listing Scraping with productLimit

## Description

Add `scrapeListing()` function to the worker that processes listing-type scraping jobs. Receives containerSelector + fieldMappings, finds all matching container elements on the page, iterates up to `productLimit` items, applies fieldMappings selectors within each container to extract data, and POSTs batch results.

## Changes

### Modify `worker/src/types.ts`
- Add `ListingJob` interface: `{ jobId, url, domainRuleId, limit, type: "listing", containerSelector, fieldMappings, selectorType }`
- Add `ListingProduct` interface: key-value map of canonical field → extracted value
- Add `ListingResultPayload` interface: `{ success: true, type: "listing", products: ListingProduct[] }`

### Modify `worker/src/consumer.ts`
- Add `handleListingMessage()` function in the `scraping_jobs` consumer branch
- Detect `type: "listing"` in message → route to `scrapeListing()` instead of `scrapeUrl()`
- Build `ListingJob` from message JSON
- POST listing result payload to `POST /api/scraping-jobs/:id/result`

### Modify `worker/src/scraper.ts`
- Add `scrapeListing(url: string, job: ListingJob)` function:
  - Opens URL with Playwright, waits for network idle
  - Finds elements matching `containerSelector` using `page.locator()`
  - If 0 matches: return `{ success: false, error: "No container elements found" }`
  - Limit count: take first `Math.min(matchedCount, limit)` elements
  - For each container element:
    - For each fieldMapping entry:
      - If `type: "text"`: `container.locator(field.selector).first().textContent()`
      - If `type: "attribute"`: `container.locator(field.selector).first().getAttribute(field.attribute)`
      - If `type: "html"`: `container.locator(field.selector).first().innerHTML()`
    - Collect into product object `{ [canonicalField]: value }`
  - Return `{ success: true, type: "listing", products: [...] }`
- Add `parsePrice()` and `detectCurrency()` reuse from existing helpers
