# Task 1.1 — Prisma Schema Migration

## Description

Extend the database schema to support the Visual CSS Selector Mapper. Add new columns to existing models and create the `FetchRequest` model for tracking page-fetch lifecycle.

## Changes

### Modify `backend/prisma/schema/models/domain_rule.prisma`
- Add `fieldMappings  Json?` — array of `{ canonicalField, selector, type, attribute? }` entries
- Add `containerSelector  String?` — CSS selector for product container on listing pages
- Add `productLimit  Int?` — default max products per scrape

### Modify `backend/prisma/schema/models/scraping_job.prisma`
- Add `type  String  @default("single")` — discriminator: `"single"` | `"listing"`

### Create `backend/prisma/schema/models/fetch_request.prisma`
- Full model: id (uuid), url, status (queued|processing|completed|failed), result (Json?), errorMessage, enqueuedAt, startedAt, completedAt, createdAt, updatedAt

### Regenerate `backend/prisma/schema.prisma`
- Run `pnpm --filter backend prisma:generate-schema` to regenerate entry point

### Run migration
- Execute `pnpm --filter backend prisma:migrate dev --name add_field_mappings`

## Dependencies

None — this is the foundation task.
