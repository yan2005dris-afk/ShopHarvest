# Task 3.3 — Save Domain Rule + Container Detection + Trigger Scrape

## Description

Complete the mapping workflow: implement container selector detection with element count highlight, build fieldMappings from user assignments, save the DomainRule via API, trigger scrape-listing, and handle the scrape result.

## Changes

### Modify `frontend/src/app/pages/visual-mapper/visual-mapper.component.ts`
- Add container selector tracking:
  - When user clicks "Set as container" → `PostMessage` to iframe asking container selector
  - Iframe JS responds with unique selector + count of matching elements
  - Display match count badge on container field
  - Highlight all matching elements in iframe with colored outline
- Add product limit input (number, min=1, max=100, default=20)
- Add "Save & Scrape" button logic:
  - Validate required fields: title AND price AND container must be assigned
  - Build `fieldMappings` array from assigned fields
  - Call `POST /api/domains/:id` (PATCH) to save DomainRule with fieldMappings, containerSelector, productLimit
  - On success: call `POST /api/scrape-listing` with domainRuleId, url, limit
  - On success: transition to SCRAPING state with job ID
  - On failure: show error, stay in MAPPING state
- Add fieldMappings builder:
  - Iterate `assignedFields` map
  - For each: build `{ canonicalField, selector, type, attribute? }`
  - If field is imageUrl: auto-detect type="attribute", attribute="src"
- Add canSave computed property:
  - Returns true only when title AND price AND container are assigned
  - Disable "Save & Scrape" button when false
- Add sidebar display of assigned fields with chip removal

### Modify `frontend/src/app/pages/visual-mapper/visual-mapper.component.html`
- Add sidebar with canonical field list (7 fields + container)
- Each field shows: label, assigned selector chip, remove button
- Add container match count badge
- Add product limit input (number field)
- Add "Save & Scrape" button with disabled state and tooltip
- Add fieldMappings preview (expandable JSON display)

### Modify `frontend/src/app/pages/visual-mapper/visual-mapper.component.css`
- Sidebar field list styles
- Field chip styles (assigned vs unassigned)
- Container highlight summary
- Limit input styles
- Button states (disabled, loading)
