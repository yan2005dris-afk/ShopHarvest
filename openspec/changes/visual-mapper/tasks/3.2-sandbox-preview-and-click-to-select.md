# Task 3.2 — Sandboxed Preview + Click-to-Select Overlay

## Description

Implement the sandboxed HTML preview inside an `<iframe srcdoc>` with injected JavaScript for click detection via `postMessage`. When user clicks an element in the iframe, show a floating menu with canonical field assignment options.

## Changes

### Modify `frontend/src/app/pages/visual-mapper/visual-mapper.component.ts`
- Add methods for iframe interaction:
  - `renderPreview(html: string)`: sanitize HTML (strip script tags, event handlers), set `srcdoc` on iframe
  - `injectClickScript(iframe: HTMLIFrameElement)`: inject JS into srcdoc context that:
    - Adds click listener on all elements
    - On click: builds `{ tag, text, selector, rect }` for clicked element
    - Prevents default behavior (no navigation)
    - Posts message to parent window via `parent.postMessage()`
  - `handleIframeMessage(event: MessageEvent)`: receive click data, store selected element, show floating menu
- Add floating menu state: `selectedElement`, `showMenu`, `menuPosition`
- Add field assignment tracking: `assignedFields: Map<string, FieldMapping>`
- Add "Set as container" option in floating menu

### Modify `frontend/src/app/pages/visual-mapper/visual-mapper.component.html`
- Add srcdoc iframe with `sandbox="allow-same-origin"` (needed for postMessage from srcdoc)
- Add floating menu positioned at click coordinates
- Add overlay highlight when element is selected

### Modify `frontend/src/app/pages/visual-mapper/visual-mapper.component.css`
- Iframe styles (full preview area, no border)
- Floating menu styles (absolute positioning, z-index above iframe)
- Highlight overlay (colored border on selected element)
- Field assignment chip styles

### Add HTML sanitization helper
- Function to strip `<script>` tags, `on*` event handlers, `javascript:` URLs from HTML before setting srcdoc
- Place in `visual-mapper.component.ts` or a shared utility
